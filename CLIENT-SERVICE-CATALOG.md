# Freelance Service Catalog — Draft

Use these as starting offers. Confirm each task is within your current skill level and adjust scope and pricing to the client.

## 1. Linux Troubleshooting Session
**Indicative introductory price:** India ₹1,500–₹3,000; international US$25–$50.

Includes a bounded diagnostic session, findings, recommended actions, and a short handover. Excludes major migrations, application code fixes, and emergency 24/7 support.

## 2. Bash Operational Automation
**Indicative introductory price:** India ₹2,500–₹6,000; international US$40–$100.

Includes one agreed script, input/error handling, logging, basic test cases, and usage documentation. Excludes ongoing maintenance unless agreed.

## 3. AWS Monitoring and Alert Setup
**Indicative introductory price:** India ₹4,000–₹10,000; international US$75–$200.

Includes agreed CloudWatch metrics/alarms, notification configuration, a test, and a runbook. AWS charges and third-party fees are paid by the client and explicitly agreed in advance.

## Before accepting work
- Confirm environment, scope, access, and rollback requirements.
- Agree on deliverables, acceptance criteria, deadline, and payment milestones.
- Use least-privilege access and MFA.
- Never promise 24/7 support unless it is separately staffed and priced.
- Do not access systems without written authorization.

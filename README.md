## How I Approach Infrastructure Work

My typical workflow is:

1. **Understand:** Identify the problem, environment, constraints, and expected outcome.
2. **Investigate:** Review relevant logs, metrics, configuration, and system behavior.
3. **Plan:** Define the solution, permissions, risks, and rollback approach.
4. **Implement:** Make controlled, documented changes.
5. **Validate:** Test the result against agreed acceptance criteria.
6. **Document:** Provide findings, operational instructions, and a handover.
